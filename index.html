    What gets templated vs. kept literal
    
      
      
    • Call-ID → [call_id]; UAC Contact host:port → [local_ip]:[local_port]. Compact header names (i:, v:, f:, t:, m:, …) are recognized and rewritten to long form.
      • 
      
    • UAC From tag → original tag text + -[call_number] (unique per run, keeps the original tag recognizable).
      • 
      
    • UAC Via → transport (UDP/TCP) preserved from the capture, extra Via params (e.g. rport, alias) kept; branch → literal token reused identically across every UAC message that shared the same branch (required for CANCEL and ACK-to-non-2xx).
      • 
      
    • To-tag on CANCEL → omitted. To-tag on ACK → [peer_tag_param], which SIPp expands to ;tag=<value> or empty string as appropriate.
      • 
      
    • ACK-to-2xx vs ACK-to-non-2xx is decided per transaction, matched by CSeq.
      • 
      
    • Re-INVITE (any UAC INVITE after the first, matched by incremented CSeq in the same Call-ID) is emitted as an in-dialog <send> with the SIPp [routes] pseudo-header, its own branch, and an annotation in the XML.
      • 
      
    • RFC 3312 precondition flows are detected when a 183 carries Require: 100rel and SDP with a=curr:qos/a=des:qos/a=conf:qos. Flow is reproduced byte-for-byte; a missing PRACK is a warning, never synthesized.
      • 
      
    • Retransmitted messages are suppressed.
      • 
      
    • All 1xx responses are emitted with optional="true", except the last provisional before a subsequent <send>, which is auto-promoted to mandatory.
      • 
      
    • Once Record-Route is seen on a ≥180 response, subsequent in-dialog UAC sends include the SIPp [routes] pseudo-header (except CANCEL and ACK-to-non-2xx).
      • 
      
    • SDP o=/c= IP → [media_ip]; m= ports → [media_port] / [media_port_N]; a=rtcp: templated to match.
      • 
      
    • If the capture is truncated at an INVITE final response, an ACK is synthesized.
      • 
      
    • Timing preservation (optional, off by default) prepends a <pause milliseconds="N"/> before each message whose delta to its predecessor was ≥ 5 ms. Capped at 5000 ms per pause.
